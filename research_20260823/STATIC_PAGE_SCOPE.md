# Static-page scope — research recommendation

## Recommended narrative

**“A calm introduction to ASMR massage and Head Spa in Plean — choose the experience, then book through Tranquil Touch’s existing service.”**

This tells a first-time visitor what is distinctive before sending them into the existing booking application. It does not promise health, medical or emotional outcomes.

## Shown in a possible polished cold demo

1. Hero: business name, Plean/Stirling locality, factual ASMR massage + Head Spa positioning, and a single `Explore booking availability` external CTA to the existing Ovatu booking route.
2. “Choose your quiet moment”: concise, evidence-backed introductions to ASMR Massage, Head Spa and A Bit of Both.
3. Reassurance/location: public address and limited opening-details summary, with a link to the existing booking route for current availability.
4. Trust close: a cautiously revalidated aggregate review signal only, or omit it if not current at build time; finish with the same external booking CTA.

## Reserved for final delivery or excluded

- Full service menu, current prices, durations, hair-length variants, child-service conditions, availability, cancellations and all operational policies.
- Appointment calendar, account/login, payments, gift-card checkout, form submission, mailing-list collection, booking management and any backend/CMS/database.
- Claims that treatments cure, treat, relieve anxiety, improve scalp conditions, create ASMR tingles for every person, or produce guaranteed outcomes.
- Testimonial quotations, ratings, practitioner credentials, portraits, studio photography, social content and logo reuse without separate customer/material authorization.

## Boundary decision

Static HTML/CSS with small front-end JS is sufficient because the dynamic operational system already exists externally. No customer data should be collected. The one CTA must remain an honest external hand-off, never an imitation booking flow.
