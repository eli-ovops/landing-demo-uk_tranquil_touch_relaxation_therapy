# v8 Design Intent — Softer tactility

v8 responds to user feedback that v6’s typography and borders felt rigid. The page keeps the real studio anchor, verified service / review / visit facts and static one-page boundary, but shifts the expression toward tactile softness: a warmer rounded sans for operational text, an expressive but gentler serif for headings, low-contrast hairlines, softly rounded action surfaces and layered translucent panels.

Motion is functional and restrained: Hero elements enter via transform/opacity; service rows reveal a subtle accent and lift; review blocks gently settle into view. No layout-property animation, auto-playing media or motion that impedes booking. `prefers-reduced-motion` disables animation.

No social, price, duration, availability, credential, review or customer photograph is fabricated.
